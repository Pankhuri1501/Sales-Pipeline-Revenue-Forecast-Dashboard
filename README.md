# Sales-Pipeline-Revenue-Forecast-Dashboard
Developed an interactive Power BI dashboard to analyze sales pipeline , revenue forecasting, opportunity conversion, and regional growth. The project includes KPI tracking, funnel stage analysis, weighted revenue forecasting, department-wise performance monitoring, and country-level revenue insights using DAX, Power Query, and visualizations.

# Sales Pipeline & Revenue Forecast Analytics Dashboard

## Project Overview
This Power BI dashboard analyzes sales performance, revenue forecasting, pipeline opportunities, and regional growth trends.

## Key Insights
- Forecast Accuracy Analysis
- Sales Funnel Monitoring
- Department-wise Revenue Performance
- Regional Growth Analysis
- Won vs Lost Opportunity Tracking
